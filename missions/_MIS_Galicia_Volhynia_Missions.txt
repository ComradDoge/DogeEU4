# Galicia and Volhynia - the Crown of Rus'
# One tree for the two Ruthenian successor states (GLA, VLH). Column 1 swaps per tag, columns 2 to 5 are shared.
# The coronation (gv_the_crown_of_rus) opens a mission preview (key GV, EE_scripted_effects_mission_rewards.txt):
# humans flip between the crown from Rome and the crown of Halicz, and Select fires gv_events.3 with that crown only
# (gv_crown_of_rome / gv_crown_of_halicz). The AI gets the event at once. Below the coronation, columns 2 and 3 exist
# once per crown (gv_c2_rome / gv_c2_halicz, gv_c3_rome / gv_c3_halicz), shown once that crown is chosen or previewed
# (gv_crown_of_*_trigger), so every arrow points at that crown's mission; "Branching Mission" placeholders
# (*_crown_unknown) stand in before. The shared nodes (Chronicle, Ruska Pravda, Rex Russiae, Lublin) take their
# trigger and reward from gv_*_trigger / gv_*_effect. gv_the_lands_of_rus only branches its reward. Nothing tied to
# the crown completes during a preview.
# Events: events/_DSE_flavour_Galicia_Volhynia.txt (gv_events), modifiers: common/event_modifiers/DST_Galicia_Volhynia_modifiers.txt
# Effects: common/scripted_effects/DST_Galicia_Volhynia_scripted_effects.txt, triggers: common/scripted_triggers/_DST_Galicia_Volhynia_triggers.txt
# Shared nodes never require a tag-only mission: a required mission that isn't in the tree blocks completion.
# The link runs the other way: each tag's second node requires gv_the_romanovich_inheritance.
