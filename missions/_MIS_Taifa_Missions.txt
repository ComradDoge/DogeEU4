# The Taifas - the road to al-Andalus
# One tree for the three Andalusi taifas (SEV, ALC, ALN). Slots 1 and 2 are each tag's own road, slot 3 (Al-Andalus)
# and slot 4 (The Maghreb) are shared, slot 5 is left to the generic tree. Forming Andalusia (decisions/AndalusianNation.txt)
# swaps this tree for the Andalusia one.
# taifa_envoys_from_the_maghreb fires taifa_events.2: the Maghrebi path (taifa_maghrebi_path) or the Andalusi way
# (taifa_andalusi_path). The four nodes below it branch on that flag; their trigger falls back to "always = no"
# while no path is chosen.
# Events: events/_DSE_flavour_Taifas.txt (taifa_events), modifiers: common/event_modifiers/DST_Taifa_modifiers.txt
# Effects: common/scripted_effects/DST_Taifa_scripted_effects.txt, triggers: common/scripted_triggers/DST_Taifa_triggers.txt
# Shared nodes never require a tag-only mission: a required mission that isn't in the tree blocks completion.
