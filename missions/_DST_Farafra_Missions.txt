# Farafra - from the oases to Kemet
# One tree for Farafra (FAF), the Kemetic oasis tribe of the Western Desert. Forming Kemet
# (decisions/_DST_FormAncientEgypt.txt) swaps it for the Kemet tree (missions/_DST_Kemet_Missions.txt).
# Slots: 1 The Oases, 2 The Desert Host, 3 The Valley, 4 The Old Gods, 5 The Throne.
# faf_the_people_of_the_river fires kemet_events.1: the Scales of Ma'at (kemet_path_maat) or the Return of the
# Neteru (kemet_path_neteru). faf_the_faith_of_the_valley and faf_the_two_truths branch on that flag; their trigger
# falls back to "always = no" while no path is chosen. Kemet's tree reads the same flags.
# Events: events/_DSE_flavour_Farafra.txt (faf_events), events/_DSE_flavour_Kemet.txt (kemet_events)
# Modifiers: common/event_modifiers/DST_Kemet_modifiers.txt, effects: common/scripted_effects/DST_Kemet_scripted_effects.txt
# Triggers: common/scripted_triggers/DST_Kemet_triggers.txt, Houses decisions: decisions/DST_Kemet_Houses.txt
